# HKSYS — Tecnologia

Site institucional de uma página única, desenvolvido para a **HKSYS**, localizada em São José dos Campos – SP.

## Sobre o projeto

Site vitrine para apresentação de projetos, capacidades do desenvolvedor, atualizações e possibilidade do usuário requesitar criação de projeto e/ou suporte técnico.

## Tecnologias

- HTML5
- CSS3 
- JavaScript puro (vanilla)
- [Font Awesome](https://fontawesome.com/) para ícones
- Google Fonts 

## Funcionalidades

- Menu responsivo com drawer mobile (hambúrguer)
- Animações de scroll
- Seções: Hero, Metrics, Sobre, Portifólio (Projetos), Blog (Atualizações), Contato, Footer
- Links diretos para Email, GitHub
- Formulário estático para contato através de email

## Estrutura

```
├── index.html
├── index.css
└── index.js

```

## Meu papel

Desenvolvimento completo do front-end: estrutura, estilização, responsividade, animações e integração.

## Rodando localmente

Não há dependências — basta abrir o `index.html` no navegador, ou usar uma extensão tipo Live Server no VS Code.
